# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.2.3-mc26.2.x] - 2026-08-31

### Changed

- Get the description id for an enchantment from the description component if possible, so that enchantments which do not derive their translated name from their registered id may show descriptions

## [v26.2.2-mc26.2.x] - 2026-06-27

### Added

- Add many new enchantment descriptions thanks
  to [VaporeonScripts](https://github.com/VaporeonScripts), [AccessIsRestricted](https://github.com/AccessIsRestricted), [RoarkCats](https://github.com/RoarkCats),
  and the original [Enchantment Descriptions](https://modrinth.com/mod/enchantment-descriptions) mod

### Changed

- Bump the bundled Tooltip Insights library to v26.2.4

## [v26.2.1-mc26.2.x] - 2026-06-26

### Changed

- Bump the bundled Tooltip Insights library to v26.2.3

## [v26.2.0-mc26.2.x] - 2026-06-18

### Changed
